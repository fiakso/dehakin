# раздача от депчика — бот

## Запуск (всё делается с телефона)

1. **@BotFather** → /newbot → имя `раздача от депчика` → получи токен.
2. Добавь бота в свой чат **админом** с правом «Приглашать пользователей» (без этого рефералка не работает).
3. Узнай id чата (например, через @getmyid_bot или @username_to_id_bot) — вида `-100...`.
4. Создай новый репозиторий на GitHub и загрузи туда `bot.py`, `requirements.txt`, `Procfile`.
5. Railway → New Project → Deploy from GitHub → выбери репозиторий.
6. Railway → сервис → **Volumes** → добавь Volume с путём `/data` (иначе база сотрётся при перезапуске).
7. Railway → **Variables**:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `CHAT_ID` | id чата (`-100...`) |
| `CHAT_LINK` | публичная ссылка на чат |
| `ADMIN_ID` | твой Telegram id |
| `SPONSOR` | `@твой_username` (подпись «от …») |
| `PROMO_TEXT` | рекламный текст под поздравлением (можно пусто) |
| `GIFT_ID` | id подарка-мишки (см. ниже) |

8. Узнать `GIFT_ID`: сначала задеплой без него, напиши боту в личку `/gifts` (только ты, по `ADMIN_ID`), скопируй id мишки в `GIFT_ID`, Railway перезапустится.
9. Пополни Stars-баланс бота — подарки отправляются с него.

Необязательно: `RAFFLE_EVERY` (по умолч. 30), `FRIENDS_PER_GIFT` (5), `RAFFLE_GIFT_ID`.
