# раздача от депчика — бот (v8)

Railway → Variables: BOT_TOKEN, CHAT_ID, ADMIN_ID, SPONSOR (обязательно), CHAT_LINK, PROMO_TEXT, RAFFLE_EVERY (по умолч. 50), FRIENDS_PER_GIFT (5), WIN_NOTE.
Settings → Volumes → путь /data.
Бот должен быть админом чата с правом «Приглашать пользователей». Напиши боту /start, чтобы он мог писать тебе.

Команды в чате: /id, /count, /raffle (только админ, запускает розыгрыш сразу).
При запуске бот присылает админу в личку «✅ Бот запущен (v8)» — так видно, что залилась новая версия.
Подарки бот не отправляет: победителей он присылает админу в личку, подарки отправляются вручную.
